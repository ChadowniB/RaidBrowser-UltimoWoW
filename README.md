RaidBrowser – UltimoWoW Edition
Addon de buscador de raids para WotLK 3.3.5a. Versión mejorada y optimizada específicamente para el servidor UltimoWoW.

Autor original: Ostoic Edición mejorada para UltimoWoW: ShadowniB G

Descripción
RaidBrowser reemplaza la pestaña LFR no utilizada en WotLK 3.3.5a por un buscador de raids funcional y optimizado para UltimoWoW.

El addon escanea los mensajes de reclutamiento en los canales globales y de chat y muestra automáticamente las raids activas en una interfaz clara y organizada.

Esto permite a los jugadores encontrar raids fácilmente sin tener que leer grandes cantidades de spam en el chat.

Esta versión incluye mejoras personalizadas para el entorno y la comunidad de UltimoWoW.

Características principales
• Detecta automáticamente mensajes de reclutamiento de raids (LFM)-POSADA • Muestra líder de raid, instancia, GS requerido y roles necesarios • Detección de guild (optimizado para UltimoWoW) • Sistema de reputación (👍 / 👎) entre jugadores (OP x UW ) • Lista limpia con temporizador y último mensaje enviado • Botón rápido para contactar al líder • Interfaz optimizada y ligera • Adaptado específicamente al sistema de chat de UltimoWoW • Mejoras de rendimiento y estabilidad

Instalación
Descargar el addon
Extraer la carpeta "RaidBrowser"
Colocar en:
World of Warcraft → Interface → AddOns

Reiniciar el juego o escribir: / reload

Abrir con: / rb

o desde: Social → Raid → Raid Browser

Uso en UltimoWoW
Para que el addon funcione correctamente debes estar en el canal global donde se anuncian las raids.

El addon leerá automáticamente los mensajes LFM-Posada y los mostrará en el panel.

Puedes ocultar el canal global del chat si no quieres verlo, el addon seguirá funcionando.

Mejoras específicas para UltimoWoW
Esta edición incluye ajustes personalizados para el servidor UltimoWoW:

• Optimización del detector de mensajes LFM • Mejor compatibilidad con el sistema de chat del servidor • Visualización de guilds • Sistema de reputación entre jugadores • Ajustes de rendimiento y estabilidad • Limpieza de código y optimización

Problemas comunes
Si el addon no aparece en el juego:

Verifica que la ruta sea: WoW/Interface/AddOns/RaidBrowser/

y que dentro estén los archivos: RaidBrowser.toc core.lua gui.lua

Si ves: RaidBrowser/RaidBrowser/ entonces está mal colocado.
